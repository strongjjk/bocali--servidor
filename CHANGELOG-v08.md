# Bocali 0.8

- leitor de PDF habilitado no ambiente local novo;
- `pypdf` incluído no perfil usado pelo iniciador/hospedagem;
- parser conservador de cardápio em `menu_parser.py`;
- resposta de PDF agora inclui produtos estruturados, categorias, nível de confiança e resumo;
- linhas com mais de um preço permanecem sem preço escolhido;
- PDF sem texto selecionável é bloqueado em vez de gerar produtos incorretos;
- tela de importação usa diretamente o rascunho estruturado do servidor;
- rascunho mostra sinal de confiança e opções de preço encontradas;
- botão para marcar apenas leituras claras como conferidas;
- criação/login de loja vazia direciona para importação do cardápio;
- versão do servidor atualizada para 0.8.
